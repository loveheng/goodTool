# 计算器 · 区块草稿台（Soulver 行模型的区块化演进）

> **Phase 1 已落地**（2026-10-21）：`BlockCanvas` 底座 = `lib/ui/components/block_canvas.dart`，页面装配 = `lib/ui/calculator_page.dart`，落点已回填 [index.md](index.md)。交互与美学口径以本文为准，视觉 token 细则不在此复制（指针 [ui-design.md](ui-design.md)）。

## 1. 定位与判定

计算器子页面的区块化交互模型：**每个区块 = 一行完整计算公式 + 内嵌预计算结果**，用户在全键盘/系统输入法上直接打出算式，结果实时就近呈现。

- 这是 Soulver 草稿台（双栏：左算式右结果列）的**渲染层演进**，不是计算模型更换——行内解析调度器 `CalculatorPort.evalLine`（纯 Dart：全角归一 / `85%` 后缀 / `<表达式> 单位 to 单位` / `ans` 引用）原样复用，内核与 MCP 工具面零改动。
- 演进动机：双栏模型存在结构性缺陷——草稿变长后左栏内部滚动与右列滚动不同步，对齐漂移；区块模型让公式与结果的呈现**同构自洽**（每个区块是完整交互单元），该缺陷从结构上消除。
- 工程量级修正：独立多 `TextField` 架构在移动端的键盘流、性能与布局边界上陷阱密集，实现量级按 **1.5~2 个工日** 计（含增删光标状态测试、折行测量与滚动避让），不按"半天"低估。

## 2. 交互规格

### 2.1 区块模型

| 项 | 规格 |
|---|---|
| 区块 = 完整公式 | 一个区块恰承载一行算式（`evalLine` 单行口径天然匹配） |
| 预计算结果 | 实时内嵌于区块（渲染与手势见 §2.4）；成功 = `telemetry` 等宽 + `l1Ok`；失败 = 机器码 + 人话（`danger`），错误圈定在出错区块内，修完即恢复——不静默、可操作 |
| 结果对齐 | 等宽字体启用 `tabularFigures`（FontFeature），多行结果右对齐时数位整齐 |
| `ans` 引用 | 指向上一**成功**区块的数值（大小写不敏感）；公式内 `ans` 词以弱胶囊背景/专属色（`dataRef`）呈现为"引用插槽"；上游改动时下游区块结果级联刷新（受控列表口径见 §5.2）。**上游故障可视化**：上游行失败导致本行不可算时，错误码标 `UPSTREAM_ERROR (Line N)` 指明故障源行——禁止让下游整串爆红却看不出根因行 |
| 块级操作 | 长按区块弹系统选择菜单（复制/剪切/粘贴，TextField 自带）；**结果单击 = 复制无损值 + 气泡反馈，长按 = 操作菜单**（§2.4）；块级"仅复制公式"经 TextField 全选复制覆盖（P1） |

### 2.2 输入校验与 Composing 隔离（CJK 致命陷阱）

- 字符校验为**软约束**：输入放行（不做 `TextInputFormatter` 硬拦——与移动端 IME 组合期注入、粘贴吞字打架），区块内实时校验，非法字符高亮下划线 + 结果位 `INVALID_CHARS`。
- **Composing 隔离铁律**：`TextEditingValue.composing.isValid`（输入法组合期，CJK 选词/注音进行中）时**绝对禁止**将当前文本传给 `evalLine` 或触发错误高亮；必须等 `composing.isCollapsed`（选词确认）后再校验。否则中文输入法选词过程中行尾结果疯狂闪烁 `INVALID_CHARS`，视觉噪点致命。

### 2.3 区块增删流（键盘流不断是本模型的成立前提）

| 动作 | 交互 | 期次 |
|---|---|---|
| 新建 | 草稿区末尾常驻空 ghost 区块（占位提示"新的一行"），点击/焦点到达即转为可输入；**不设"+"按钮** | P1 |
| 末块回车 | 结束当前区块、焦点跳下一区块（不插入 `\n`） | P1 |
| 空块退格 | **两段式删块**：空块上第一次退格不销毁——块上显示"再按一次删除"微提示；第二次退格才整块消失、焦点落上一区块。防连按退格串行销毁上一行有效公式（比纯时间冷却更确定，不依赖计时竞态）。**状态重置**：任何文本变动（`text.isNotEmpty`）或失焦（`hasFocus == false`）必须立即清除该块的待删除态与微提示——否则改主意输入数字/切焦点后，旧待删除态残留导致下次退格秒删 | P1 |
| 空白区命中 | 滚动容器非块区域（列表剩余空白）点击 = 聚焦末尾 ghost 块并拉起软键盘——键盘弹出时 ghost 常被推到可视区外，点空白是用户算完一行的自然下一步，禁止点空无响应 | P1 |
| **光标中段回车 = 拆块** | 光标在 `100 + | 200` 按回车：当前块截断为 `100 +`，新建下一块内容 `200`，焦点跳入下一块起始位——中段回车直接跳走不拆文本会破坏断句直觉 | P2（P1 可先只支持行尾回车跳块） |
| **非空行头退格 = 合块** | 光标在第二行行首退格：第二行内容拼接到第一行末尾并销毁第二块 | P2（P1 暂不拦截，按默认行为） |
| 排序 | 长按拖拽 | v2 |

- **焦点防跳变**：新建/切换区块时，先挂载新 `FocusNode` 并 `requestFocus()`，再注销/失焦前一个——保证焦点树任意时刻都有驻留，防软键盘 1 帧内闪退或高度震荡（Jitter）。

### 2.4 行内结果的渲染选型

- **严禁 Overlay**（全局/绝对定位 Overlay 难跟随列表滚动，管理成本极高）。
- 选型：单区块内 `Row` + 结果 `IntrinsicWidth`（或 `CustomMultiChildLayout`）两段式布局：`[公式输入 (Flexible)] ···· ≥12dp 留白 ···· [结果]`。
- **沉降切换（含尺寸迟滞）**：公式测量宽（`TextPainter`）+ 结果宽 > 区块可用宽时，自动从同行模式切为纵向两行模式——公式占第一行全宽，第二行右对齐渲染结果（带 `= ` 前缀弱化箭头感）。阈值**迟滞**防边界抖动：进入两行 ≥95% 可用宽、退回单行 ≤75%——编辑在阈值附近增删字符时不产生整列表纵向跳动（Layout Shift），光标不跟随跳跃。**兜底截断**：两行模式下公式或结果仍超宽（超长公式折行 / 大位宽高精度值 / 长错误码）时，结果槽锁 `maxLines: 1` + `TextOverflow.ellipsis`，排版不撑爆；复制一律取**底层完整未截断原始值**（排版可截，数据无损）。
- **结果区手势（与输入区物理解耦）**：结果段是独立的 `GestureDetector`，**阻断事件穿透**——绝不让点结果聚焦输入框拉起软键盘（计算器用户点结果 90% 意图是取数，穿透会把光标扔进公式末尾，体验反直觉）。**单击** = 复制无损 `numeric` + 轻量气泡反馈；**长按** = 操作菜单（复制格式化串 / 在下一行插入该值）。

## 3. 功能边界与补偿（双栏 → 区块的退化防护）

区块化在带来块级操作增益的同时，相对双栏模型存在三处**功能性退化**，须按以下口径主动补偿，禁静默劣化：

| 退化项 | 机理 | 补偿口径 | 期次 |
|---|---|---|---|
| **跨块文本选择缺失** | 多 `TextField` 架构切断系统级跨框选择——长按拖动光标无法跨越两个区块，双栏的整段划选不复存在 | 草稿区提供**纯文本查看/导出**入口（全稿按行拼接，只读页可跨行选择、一键复制）；块内选择仍走 TextField 原生能力 | P2 |
| **多行粘贴破坏单行假设** | 外部复制的多行算式粘入单行区块时，Flutter 默认**静默过滤 `\n`**（内容并作一块，换行丢失且无提示）——恰是"静默降级"反模式 | 实现**粘贴裂变**：粘贴内容含 `\n` 时拦截，按行 split 自动生成 N 个连续区块（沿用 composing/校验口径逐块求值）；**>30 行弹确认**（"检测到 N 行文本，是否批量创建为 N 个计算块？"）；裂变记为**复合事务**，Page 级保存前快照，提供单次撤销整体回滚（多 TextField 割裂了系统 Undo，必须应用层自建）；裂变完成后**焦点统一收敛到最后一个新块的行尾**，并 `Scrollable.ensureVisible`（~200ms）平滑跟随——防键盘压缩视口时突发插入多项导致视口跳跃、用户丢失光标位置 | P1 |
| **信息密度下降** | 单块需承载聚焦命中区与结果位，行高 ~40-48dp（双栏可压至 24-28dp），一屏可视行数缩减 30-50% | 行高对齐 `metrics` 阶梯取紧凑档；结果仅超宽时才沉降（常态保持单行）；不做花哨块内留白——密度是有意的代价，靠就近可读性换回 | P1 即按此实现 |

功能增益侧（区块模型独有、双栏难以实现）按价值排序，分期见 §6：块级独立错误圈定与复制（P1）、注释/分节块（P2）、块禁用 What-if 分析与拖拽重排（v2）、依赖关系可视化（v2）。

## 4. 美学规格（**草稿纸模型**，2026-10-21 用户裁决修订）

> 修订动因：原「每块 surfaceSunken 色块 + 4dp 微缝」与「一张计算纸的沉浸感」自相矛盾——逻辑上是区块模型，视觉上不应让人看出区块。**分块是逻辑/交互单元（焦点链、删块、裂变、ans 级联），不是视觉容器。**

| 项 | 规格 |
|---|---|
| 纸面 | 整页 `surface` 底色直出（无尽纸卷：顶底各 16dp 内边距，软键盘不挤变形）；块体**透明**，零底色、零圆角、零块缝——行间呼吸感由排版行距与内容 padding 撑起 |
| 聚焦行 | **IDE 式行光标带**：整行 `surfaceRaised` 高亮（token 全值，禁 withOpacity 裸值）+ 左缘 2dp 强调竖条**仅聚焦行出现**（双通道不单靠颜色） |
| 聚焦引线 | **Leader Dots**：聚焦行公式末尾到输入区右缘铺点阵（画在 TextField 之下的空区），视线在长留白中穿透到行尾结果；点阵间距 grid×2、半径 borderWidth，色 `hairline` |
| Gutter | 左缘行号轨（微字轨 `micro`）：弱化 `NN` 编号色 `textMuted`、错误行标红 `danger`、待删除行覆盖删除图标；**点击行号聚焦该行**（行号多选/快速清除、长按拖拽排序锚点 → v2） |
| 错误定位 | 行内下划线 `danger` + 行尾结果位 `danger` 机器码 + 对应 Gutter 行号标红；**上游故障提示可点击 → 平滑滚动聚焦根因行** |
| `ans` 标签 | 公式中 `ans` 词弱胶囊/`dataRef` 专属色（P2 行内高亮落地时） |
| 排印 | 公式 = 阅读轨 `body`；结果 = 遥测轨 `telemetry` 等宽 + `tabularFigures`；行高字号全走 token，零魔法值 |
| 动效 | 聚焦迁移 ≤200ms（`motion.durationSlow`，Ease-Out），禁 Spring |

### 4.1 纸面功能补全（2026-10-21 用户补充，随草稿纸模型同轮落地）

去卡片化后依附在容器上的功能锚点由以下纸面级能力补偿：

| 能力 | 规格 | 裁决 |
|---|---|---|
| 结果轨道吸附 | 单行结果严格右对齐统一遥测轨道 + `tabularFigures`；聚焦行公式末尾 → 行尾铺 Leader Dots 引线 | 直采 |
| Gutter 行号轨 | 左缘微字 `NN` 编号；错误行标红；待删除行覆盖删除图标；点击行号聚焦该行 | 点击=聚焦；**行号多选/快速清除、长按拖拽锚点 → v2**（拖拽排序本为 v2，多选为新需求同期登记） |
| Telemetry 汇总条 | 纸张底部常驻读数条：`有效行 / 最终 ans / 累计总和` 实时刷新；点击读数复制该值 | 直采（「插入该值」并入结果槽长按菜单「在下一行插入该值」，不重复建口） |
| 纸面全局动作 | 标题行 Action 区：一键全纸复制（`[公式] = [结果]` 逐行）、纸面清空（二次确认归零至单行）、Reader Mode（纯文本渲染层，可跨行划选，补跨块选择缺失） | 直采 |
| 上游故障导航 | 点击 `UPSTREAM_ERROR (Line N)` 提示 → 平滑滚动并聚焦根因行 | 直采 |
| Ghost 占位行 | 纸面末行淡灰占位文字，点击行内任意水平区域即获光标 | 直采（占位文案 `// 输入公式或单位换算…`） |

### 5.1 区块组件化抽取口径（BlockCanvas = 基础设施，计算器 = 首个消费者）

**抽取边界——四进三出**：

| 进底座（无领域语义，可复用） | 留业务层（领域专属，回调/槽位注入） |
|---|---|
| 焦点链管线（FocusNode 池、防跳变、空白命中聚焦 ghost） | 求值/执行引擎（`evalLine` 等经 `onInputChanged` 回调注入） |
| IME Guard（composing 期切断对外通知，`isCollapsed` 后才 emit） | 结果语义渲染（`outputBuilder` 槽位——数值/机器码/遥测样式是业务的事） |
| 粘贴裂变协议（`\n` 拦截、>30 行确认、复合事务快照回滚） | 依赖图（`ans` DAG 解析归页面 ViewModel，底座只认一维区块列表） |
| 弹性槽位引擎（`TextPainter` 测量、迟滞沉降、结果槽截断兜底） | |

**API 口径（v1 最小面）**：

- **非泛型**：不引入 `<TInput, TOutput>` 双泛型——首个消费者只有 `String` 输入，且输出经 `outputBuilder(BuildContext, int index)` 直接产 Widget，领域类型对底座不可见；第二个消费者出现若真需泛型再加（加兼容、删不兼容）。
- **状态三态收窄**：`BlockStatus { idle, busy, done }`——底座只区分"无结果位 / 占位 / 内容槽"；成功/失败的语义色（`l1Ok`/`danger`）是业务渲染职责，底座禁持语义色。
- **回调面**：`onInputChanged(index, text)` / `onBlockSplit(index, offset)` / `onBlockRemove(index)` / `onPasteFission(index, lines)`——增删流事务由上层（Page 的 `List<LineRecord>`）统一记账，底座无状态。

**复用与防旁路**：

- 潜在后续消费者：MCP 工具调用调试台（入参块 + 状态机结果槽）、网络探针序列（命令块 + 遥测槽）、规则/KV 配置列表——交互形态同构，`outputBuilder` 槽位即可承载。
- **红线**：任何业务需要键盘流/裂变行为时，先扩底座再消费；业务侧绕过底座自持焦点管理或粘贴逻辑 = 禁止（防底座被旁路退化为摆设）。底座演化只加不改语义；改语义需过方案准入。

**决策依据**（对照"Extract, Don't Speculate"的取舍）：本仓键盘流代码经逐条审查**不含领域语义**，"写死 calculator 再上移"省下的 API 猜错风险，由"回调收口 + 最小面"替代对冲；而第一天写对落点（`lib/ui/components/`，登记制管辖）直接省掉一次确定性搬迁重构。

### 5.2 受控列表与 ans 级联（响应式依赖链）

区块本质形成 DAG 依赖链（Block1 → ans → Block2 → …），状态设计硬约束：

- **结果不落区块本地 State**：Page 级维护统一 `List<LineRecord>`（行文本 + CalcView），区块 UI 是**纯受控组件**——上游修改经一次 `setState()`（或局部状态驱动）整齐刷新下游，禁止各块自持计算结果（否则级联必裂）。
- **聚焦块免回写（光标保护硬约束）**：每个区块持有独立 `TextEditingController`；数据流单向——**当前聚焦块（`hasPrimaryFocus`）的 Controller 是文本的唯一驱动源**，输入期间严禁 Page 级 State 反向 `controller.text = …` 回写（会把光标暴力重置到开头/末尾）；仅非聚焦的下游块接收级联重算通知。级联刷新只写 `LineRecord` 的结果字段，永不触碰聚焦块的文本字段。
- 长列表滚动：区块用 `ListView` 承载，`TextField` 状态随 `LineRecord` 走，滚动重建不丢内容（对齐设置页 `AutomaticKeepAliveClientMixin` 口径）。

## 6. 演进节奏

| 阶段 | 内容 |
|---|---|
| **Phase 1（核心交互收敛）** | **以 `BlockCanvas` 组件形态实现（§5.1），计算器页只做装配**；统一受控列表 + 单行输入与行尾弹性结果；回车跳下一行、空块退格删除、末尾 ghost 占位；结果超宽自动沉降第二行；**粘贴裂变**（多行粘贴自动生成 N 块）；块级结果复制；**CJK composing 隔离**（实现成本一行守卫，且 P1 验收第 3 条即依赖——不前移则中文输入法下 P1 验收必挂） |
| **Phase 2（健壮性 + 体验补全）** | 光标中段回车拆块；`ans` 级联联动与引用高亮；非空行头合块；**注释/分节块**（全宽纯文本块，不触发求值）；**纯文本查看/导出**（全稿按行拼接，补跨块选择缺失） |
| **v2（高级工作流）** | 长按拖拽排序；块级临时禁用/静音（What-if，禁用块退出 `ans` 级联链）；依赖关系可视化（上游引用高亮 / 下游同步提示）；**统计汇总块**（`sum`/`total` 聚合前序成功块——**需扩展 `evalLine` 聚合能力，属内核端口演进而非 UI 功能**，落地前先过方案准入（收敛条件见 `context/decisions.md` 2026-10-21 ADR）） |

## 7. 验收清单（实现轮逐项自证）

1. arch-guard 7/7、`flutter analyze` 0 issue、`flutter test` 全绿（含区块首帧 widget 测试与 `evalLine` 存量单测）；
2. 回车 = 跳下一区块；空块回退 = **两段式删块**（首退格仅出"再按一次删除"提示）；空白区点击 = 聚焦 ghost 块拉起键盘；焦点切换无软键盘闪烁（手动真机验证）；
3. 非法字符 = 区块内高亮 + `INVALID_CHARS`，放行输入不吞键；**composing 期间零校验零高亮**（中文输入法选词过程结果位不闪烁）；
4. 行尾结果超宽自动沉降第二行且**阈值迟滞生效**（95%/75% 边界附近连续增删字符无整列表跳动）；**点结果 = 复制 + 气泡反馈（不聚焦输入框不弹键盘），长按 = 操作菜单**；
5. `ans` 引用失败分两类可辨：本行语法错 = `ANS_UNAVAILABLE`/语法机器码；上游故障 = `UPSTREAM_ERROR (Line N)` 指明根因行；上游修复后下游级联恢复（受控列表单源验证）；
6. **粘贴裂变**：外部复制 3 行算式粘入任一区块 → 自动生成 3 个连续区块并逐行求值，无静默并块、无换行丢失；**>30 行弹确认**；裂变后应用层单次撤销可整体回滚；
7. **聚焦块光标稳定**：输入过程中级联刷新不重置当前块光标位置（widget 测试断言 `TextEditingValue.selection` 不变）；
8. 真机侧载视觉验证（聚焦轨 / 沉降 / 深浅主题 / 一屏密度 / 50+ 区块滚动流畅）。
